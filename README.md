# Hangyi Liu — Academic Homepage

Personal academic homepage built with the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme and hosted on GitHub Pages.

## Features

- Responsive Minimal Light academic layout
- Manual light and dark theme switching
- English and Simplified Chinese content switching
- Theme and language preferences remembered in the browser
- Automatic first-visit defaults based on system theme and browser language

## Sections

- About
- Research interests
- News
- Selected projects
- Publications
- Contact
